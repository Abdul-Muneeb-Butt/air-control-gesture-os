# Air Control - Touchless Gesture Control (Linux)

Touchless Multimodal Control System - Gesture and Voice-Based Laptop Interaction Using Linux

Group: Abdul Muneeb, M. Qasim

## Hardware
- Arduino + 2x HC-SR04 ultrasonic sensors

## Run
